# Blog Management System

A responsive full-stack Blog Application built with HTML, CSS, JavaScript, Node.js, and Express.

## 🚀 Live Demo
- **Live Website:** [Click Here to View Live](https://swathisenthil0208-hub.github.io/blog-management-system/)
- **GitHub Repository:** [Click Here for Code](https://github.com/swathisenthil0208-hub/blog-management-system)

## ✨ Features
- Create, view, edit, and delete blog posts.
- Responsive user interface optimized for mobile and desktop screens.
- Clean layout with modern CSS styling.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **Hosting:** GitHub Pages
